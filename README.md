# AKUMA — نسخه آغازین
پروژه فارسی و راست‌چین مانهوا/مانگا/کمیک.

## انتشار
این پروژه با Vite ساخته شده است. Build command: `npm run build` و Output directory: `dist`.

## راه‌اندازی توسعه
Node.js 18+، سپس `npm install` و `npm run dev`.

## پایگاه داده
فایل `supabase/schema.sql` اسکیمای اولیه است. ورود واقعی، پنل مدیریت و بارگذاری فصل‌ها در مرحله اتصال Supabase تکمیل می‌شوند. محتوای منتشرشده باید متعلق به شما باشد یا مجوز بازنشر آن را داشته باشید.

نمونه‌های فعلی فقط برای نمایش ظاهر و جریان اولیه هستند.
